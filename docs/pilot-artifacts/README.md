# MTM Routes Phase 1 demo workbook

`mtm-phase1-customers-demo.xlsx` is a sanitized version `1.0` customer import
workbook generated by `scripts/mtm-routes-phase1-pilot-workbook.mjs`. It contains
no real customer data.

| External code | Example operation | Purpose |
| --- | --- | --- |
| `000P10715` | Create | Proves leading-zero codes remain text through import and export. |
| `P1-20260715-P01` | Update | Proves an existing customer can be previewed and updated. |
| `P1-20260715-D01` | Unchanged | Proves matching rows do not create unnecessary writes. |

The same generated workbook completed the production preview, apply, replay,
history, and export gates documented in `docs/mtm-routes-phase-1-pilot-evidence.md`.
