# Кадровый учёт: первый рабочий день

Это инструкция для меню с разделом «Кадровый учёт» слева. Пока обновление
навигации не опубликовано, те же страницы доступны через прежнее меню MTM.

## Подготовка администратором

1. В настройках MTM откройте «Компания → Модули», включите «Учёт рабочего дня»
   и сохраните. В азербайджанском интерфейсе: «Şirkət → Modullar → İş vaxtının uçotu».
2. Откройте «Кадровый учёт → Сотрудники». Активные пользователи компании уже
   включены автоматически. Создавать ещё 300 карточек вручную не требуется.
3. Найдите тех, кого не нужно учитывать в табеле, и отключите их участие.
   Это не меняет их роль и не превращает офисного сотрудника в полевого.
4. Приём, увольнение и повторный приём вносите в историю только при наличии
   действительного кадрового события. «Основание» — объяснение такого события,
   например номер приказа. Для обычного автоматического включения оно не нужно.
5. Выдайте кадровику необходимые права. Доступ HR к общему просмотру позволяет
   читать данные; сам по себе он не даёт права принимать решения по заявкам.
   Проверяйте действия под учётной записью уполномоченного руководителя или
   администратора.

Сбор геоданных оставьте выключенным до утверждения текста согласия. Адресатов
рассылки по умолчанию нет: добавляйте их только когда нужна отправка. Для первого
проверочного дня QR и подтверждение установки телефона включать не обязательно.

## Что делает офисный сотрудник

1. Открывает актуальное приложение MTM, выбирает свою компанию и входит с
   обычной учётной записью. После включения учёта уже вошедший сотрудник может
   свернуть приложение и открыть снова, чтобы обновить доступ.
2. На экране «Рабочий день» нажимает «Начать день». Дожидается «День идёт».
   «Ожидает подтверждения» означает, что отметка ещё не подтверждена сервером.
3. Для временного отсутствия нажимает «Перерыв», после возвращения —
   «Продолжить день».
4. В конце работы нажимает «Завершить день» и подтверждает уход. Закрытие
   приложения само по себе рабочий день не завершает.
5. Если после завершения нужно продолжить работу, использует «Вернуться к
   работе», когда кнопка доступна. Это возможно в тот же день; уже проверенный
   или исправленный руководителем день может быть закрыт для возврата.

При отсутствии сети сохранённая очередь остаётся на телефоне. После восстановления
связи проверьте подтверждённое состояние. Если сервер отказал, используйте
обновление и сообщение на экране; не считайте ожидающую отметку принятой.

## Заявки сотрудника и проверка кадровиком

Сотрудник открывает «Мои заявки → Новая заявка», выбирает вид, даты и при
необходимости часы, пишет причину и подаёт заявку. Формат даты показан у поля:
год-месяц-день. Непринятую заявку можно отменить; статус и ответ руководителя
появляются в том же списке. У полевого сотрудника «Мои заявки» находятся в «Ещё».

Кадровик открывает «Кадровый учёт → Заявки» и проверяет период, причину и документы.
Уполномоченный проверяющий одобряет или отклоняет обращение; при отклонении
указывает причину. В «Истории решений» можно проверить результат. Изменение
начала или ухода оформляется заявкой на исправление, исходные отметки сохраняются.

## Как сверить результат

- В «Табеле» выберите нужный период и сотрудника. Сравните начало, перерывы,
  завершение и итоговое время с телефоном. Обновите данные после синхронизации.
- Проверьте заявку в списке сотрудника и решение в веб-интерфейсе.
- Скачайте Excel или PDF для выбранного отчёта. Специальный формат бухгалтерии
  пока не согласован.
- «Проверка отметок» показывает поводы для разбора. Само замечание не доказывает
  нарушение и не должно автоматически менять отработанное время.
- Закрывайте месяц после проверки данных и устранения указанных препятствий.
  Раздел «Закрытые месяцы» сохраняет итоговый снимок и его выгрузки.

Для пробных отметок и заявок используйте отдельную тестовую компанию. Не
завершайте реальный рабочий день только ради проверки кнопки.
