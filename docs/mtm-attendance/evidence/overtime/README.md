Фактическое превышение: max(0, окончательные отработанные часы − план). Порог проверяется отдельно и не вычитается из часов. Отсутствующий порог неизвестен. Расчёт использует общий учёт пауз и UTC-длительность смены. Незавершённые и недостоверные дни не дают окончательных часов.

Согласование проходит через существующую заявку OVERTIME. Часы разрешения не доказывают работу и не определяют оплату. Пересекающиеся разрешённые интервалы объединяются. Для ночной смены разрешение следующего дня относится к единственной пересекающейся записанной смене; иначе — к дате заявки. Неоднозначные совпадения и неверные часовые пояса показаны неизвестными.

Сохранённые формы и расписания используют режим OVERTIME и обычную проверку доступа. Адреса по умолчанию пустые; внешние письма не отправлялись.
