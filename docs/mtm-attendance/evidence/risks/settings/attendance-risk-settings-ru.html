Как работают агенты: визиты, маршруты, оповещения.

Составление маршрутов

Несколько агентов в одном маршруте
В маршрут можно добавить основного агента и помощников.
Показывать время в пути
Между точками маршрута показывается время в пути по Google Maps. Работает, только если для вашей компании подключён Google Maps; иначе время не показывается.
Ссылка на путь в Google Maps
У следующей точки маршрута появляется ссылка, открывающая путь в Google Maps. Порядок точек она не меняет.
Не ставить маршруты на нерабочие дни
Маршрут нельзя запланировать на день, который в рабочем календаре отмечен нерабочим.

Модули

Клиенты (врачи, фармацевты и др.)
Если выключить, раздел пропадает из меню и из приложения агента. Данные не удаляются.
Аптечные промо
Если выключено, скрываются из меню и из приложения агента; данные не удаляются.
Учёт рабочего дня
Выключено по умолчанию. Включает отчёты о рабочем времени в MTM; доступ к данным определяется правами пользователя.
Отклонять отметки вне филиала
По умолчанию выключено: такие отметки принимаются с пометкой. Если включить, отклоняются только отметки с подтверждённым местом вне филиала. Без согласия, без GPS, при неточном месте и в старой версии приложения время принимается.

Агенты в приложении

Агент сам создаёт себе задачи
Агент может создавать и вести свои задачи в приложении.
Свои задачи могут повторяться
Агент может сделать свою задачу повторяющейся.
Агент видит встречи своей команды
Агент видит, кто из его команды, когда, где и с каким клиентом встречается. Телефоны, заметки и текущее местоположение коллег не показываются.

Проверка отметок рабочего дня

Разрешить общий телефон
Включите, если сотрудники законно пользуются одним телефоном. Новые совпадения одной установки приложения у разных сотрудников за день не создают замечаний. Уже записанные замечания сохраняются.
Отклонять отметки с подменой места
По умолчанию отметка принимается с замечанием. При включении отказ происходит только при явном признаке подмены. Отсутствие GPS, согласия или сведений от старой версии приложения не означает подмену.
Порог разницы времени
По умолчанию 300 секунд. Разница между временем телефона и получением на сервере — повод для проверки; её может вызвать потеря связи. Доставка позже 15 минут отмечается отдельно. Допустимо от 30 до 86400 секунд.

Меняется редко

Применять правила визита
Пока выключено, ни одно правило не действует: агенту показываются все действия, и ни одно не обязательно. Сами правила сохраняются.
Потенциал бренда — отдельно по каждому агенту
Потенциал и охват врача по бренду хранятся отдельно для каждого агента, а не одним числом на врача.
Загрузка данных из Excel
Сотрудники с правом загрузки могут проверять и загружать файлы Excel в MTM.
Технические пороги GPS-истории

От них зависит, как из точек GPS считаются путь и остановки. Обычно менять не нужно; изменить может только администратор CRM.
