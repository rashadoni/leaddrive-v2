2. Complete actual localized visibility, explanation, keyboard/read order,
   pagination, contrast, safe error/denial and persisted-fact distinctions.
   Reproduce any defect before applying a scoped fix.
3. Supply actual assistive-technology execution. The current Linux environment
   has Chromium, D-Bus, AT-SPI, Gtk3 and GI via `/usr/bin/python3`; the default
   Python's missing GI was a false capability conclusion. Orca and its complete
   speech/typelib/display dependency stack are not installed or tested.
4. If the authorized package route is available, resolve exact official package
   versions/hashes, extract to a disposable workspace prefix without sudo,
   maintainer scripts or system configuration changes, and use a private D-Bus,
   display and browser profile. Use only synthetic tenant/accounts. An observed

5. Verify the real Chromium-to-AT-SPI bridge and actual Orca event/key processing
   and presentation output. An accessibility tree or mocked announcement is not
   a screen-reader run. Measure locale support and the absent employee's observed
   name, plan and explanation; retain only minimized synthetic results and
   package/source bindings. No public narration or production audio service.
6. Complete meaningful PostgreSQL/role compatibility, applicable exact-head CI,
   independent source and evidence review, and durable originals. Only then
   update WF-C8-002 and its derived ledger. Stop only owned test processes.
