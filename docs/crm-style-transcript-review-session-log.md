### Приоритеты для возможной следующей задачи

1. P2: привести контраст основных кнопок к единому правилу. Почти чёрный цвет — возможный выбор, а не обязательное требование: более тёмный оранжевый также решает контраст.
2. P2: сократить конкурирующие цвета в лидах, прежде всего у источника и обычных категорий; сохранить функциональные статусы, подписи, семантику графиков. Не объявлять любой категориальный цвет ошибкой.
3. P2: если нужен именно стиль транскрипции, подготовить спокойный вариант dashboard и сравнить с текущим. Видеообои и navy command-deck закреплены в `.impeccable.md` как намеренное оформление; это изменение направления, а не автоматическая правка дефекта.
4. P3: только после этого сравнить нынешний слегка холодный серый с нейтральным. Разница менее значительна, чем цветные бейджи и большие акцентные поверхности.

Тёмно-синий sidebar сохранён по прежнему пожеланию пользователя (`globals.css:34–36`). Активный пункт использует оранжевый маркер и белую иконку (`src/lib/nav-items.ts:506–507`, `src/components/sidebar.tsx:415–422`); перекрашивать sidebar в рамках такого сравнения не требуется.

По стилю впечатление от «AI-шаблона» сильнее создают градиенты, стекло и декоративный фон, чем светло-серая основа. Это оценка исходных правил, а не заявление о просмотренном рабочем экране. Строгая нейтральность и чёрные кнопки сами по себе не гарантируют качество. Правило «выше — светлее» полезно для системы поверхностей, но не является требованием ко всем элементам страницы.

## 2026-10-25 — диагностика WebSocket disconnected

- Пользователь показал выполнение SSH-туннеля на Mac, затем снимок открытого через приложение внешнего DevTools frontend с сообщением `WebSocket disconnected`.

- Причина внешнего frontend воспроизведена точным probe: WebSocket с Origin `https://chrome-devtools-frontend.appspot.com` получает HTTP 403 от Chrome. Прежняя прямая HTTPS-ссылка непригодна при текущей защите Origin.
- Исправленный путь ручного доступа: собственный Google Chrome на Mac, `chrome://inspect/#devices`, Discover network targets → Configure → `127.0.0.1:9223` → inspect у вкладки `[LLM] LeadDrive CRM — visual review`. Native DevTools использует транспорт браузера, а не WebSocket с Origin внешнего сайта. Независимая проверка по первичным исходникам Chromium подтвердила механизм.
- Не ослаблялись Origin-проверки, не добавлялись allow-all флаги, браузер и его профиль не перезапускались. SSH-туннель пользователя остаётся прежним. Ожидается ручной вход; внутренний визуальный аудит всё ещё NOT RUN.
