Уполномоченный HR явно отмечает ошибочное срабатывание независимо от исхода
апелляции: удовлетворена полностью, удовлетворена частично или отклонена.
Частичный исход показан отдельно. Решения дописывают существующий неизменяемый
журнал с актором, причиной, операцией и ревизией; API и RU/AZ/EN интерфейс
сохраняют MFA, роли HR, изоляцию тенантов, приватность, проверку ревизии и
идемпотентности. Кадровые решения автоматически не принимаются.

Окончательные проценты используют собственные выборки классифицированных
рассмотренных случаев текущего закрытого цикла. Открытые, повторно открытые,
неклассифицированные и повреждённые истории исключаются; размеры выборок и
незавершённые случаи показаны отдельно. Пустая выборка возвращает null и не
показывает процент. Связи с коррекциями табеля показаны количеством и размером
когорты, не означают ошибку системы или удовлетворённую апелляцию. Историческое
описательное отношение сохранено в API для совместимости; оно не является
окончательным HR-исходом. CASE_RECORDED_AT сохранён. Время измеряется до первого
записанного решения, закрывающего случай, по календарным часам; повторное открытие не перезапускает
этот исторический показатель.
