## 1. Классификация информации (контроль 5.12)

Четыре уровня. Больше для компании из пяти человек не нужно, меньше — не
позволяет отделить чужие данные от своих.

| Класс | Что это | Правило обращения |
|---|---|---|
| **К4 — данные арендаторов** | клиентские базы, переписка, записи звонков, счета чужих компаний | шифрование при хранении и передаче, доступ только через приложение с RLS, вынос за пределы системы — только через штатный экспорт с записью в журнал |
| **К3 — конфиденциальная** | секреты, ключи, учётные данные, исходный код, персональные данные сотрудников | доступ по необходимости, хранение только в предназначенных для этого местах |
| **К2 — внутренняя** | документация, планы, переписка компании | не публикуется |
| **К1 — публичная** | сайт и утверждённые маркетинговые материалы | ограничений нет |

**Особенность, которую надо понимать.** К4 — это данные **третьих лиц**, за
которые компания отвечает по договору. Утрата К3 бьёт по компании; утрата К4
бьёт по клиентам компании и по её праву работать дальше. Поэтому классы
разделены, хотя технически оба «конфиденциальные».

## 4. Криптографические ключи и секреты (контроль 8.24)

Отдельный раздел намеренно: это те активы, потеря которых необратима, а
компрометация — тотальна.

| Секрет | Где живёт | Кто имеет | Риск |
|---|---|---|---|
| Приватный ключ SSH к production | GitHub Actions Secrets | владелец | компрометация GitHub = компрометация прода (S-02) |
| Закрытая `age` identity для резервных копий | вне production; место и дублёр ⟨подтвердить⟩ | владелец | production хранит только публичный recipient; deploy требует successful encrypted restore-canary backup |
| `DATABASE_URL` и пароль БД | `/etc/leaddrive/app.env` на production | владелец | checkout `.env` — только compatibility symlink |
| `NEXTAUTH_SECRET` | там же | владелец | подделка сессий при утечке |
| `CLOUDFLARE_API_TOKEN` | там же | владелец | перехват домена и почты |
| Ключи AI-провайдеров, каналов, платежей | там же | владелец | финансовый и репутационный ущерб |
| `CRON_SECRET` | там же | владелец | запуск фоновых заданий извне |

**Общий вывод по разделу.** Все секреты сходятся к одному человеку и к одной
машине. Это и есть F-06 в конкретном выражении: не «нет процедуры», а
«одиннадцать ключей, каждый в одном экземпляре».

## 7. Что требуется от владельца

Только строки **⟨подтвердить⟩**. Их девятнадцать, и почти все — это «да/нет»
про второй фактор и владельца аккаунта. Разделы 1–4 и 6 собраны без вашего
участия.
