# ISMS-16. Анализ со стороны руководства, несоответствия и корректирующие действия

| | |
|---|---|
| Документ | ISMS-16 |
| Требования | ISO/IEC 27001:2022 п. 9.3, 10.1, 10.2 — обязательные записи |
| Проводит | директор Fanumsec MMC |
| Периодичность | не реже раза в год; перед Stage 2 — обязательно |

> Анализ со стороны руководства — не совещание, а **запись с решениями**.
> Аудитор проверяет две вещи: рассмотрены ли все обязательные входные данные и
> приняты ли по итогам решения с ответственными. Протокол на одну страницу с
> решениями лучше, чем на десять без них.

## 2. Обязательные выходные данные (п. 9.3.3)

Решения по: возможностям улучшения, необходимости изменений в СУИБ, потребности
в ресурсах. Каждое решение — с ответственным и сроком.

## 4. Несоответствия и корректирующие действия (п. 10.2)

Несоответствие — любое невыполнение требования: находки аудита, нарушение
собственной процедуры, повторяющийся инцидент.

Порядок: отреагировать и устранить последствия → **проанализировать причину**
→ определить, есть ли подобные несоответствия в других местах → внедрить
действие → проверить результативность → записать.

Ключевой момент, который проверяет аудитор: разобрана ли **причина**, а не
только следствие. «Забыли выставить флаг» — не причина; причина в том, что
процесс позволяет забыть.
